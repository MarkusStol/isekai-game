Measured on box 2026-10-28 (Europe/Berlin).

Unit tests: `node test-v13.1.mjs` — 14/14 pass.
Browser smoke: `node test-v13.1-browser.mjs` — talk +8 min, eat +30 min, catch-up opt-in, ver=131.

## TTFT architecture
- Continuity block capped (~2–3k tokens, `TOKEN_BUDGET_CHARS=9000`).
- First tokens: Gemini SSE streams immediately; `S._ttft` recorded on first non-empty chunk.
- AFTER reply (idle): chapter rollup, world apply, quests, scene image, portrait, `worldTick`, save.
- `worldTick` no longer advances hours (was the main time-jump bug).

Live Gemini TTFT depends on network/key; debug HUD shows `Zug X ms · TTFT Y ms · ~Z tok` when debug is on.

## Time fixes
- Conversation turns: minutes (talk 5–15, default 8).
- Eat ~30, travel by distance class, sleep until 07:00 (4–12h).
- Narrator `durationMin` clamped per action type; day jumps only for sleep/far travel/work.
- Offline catch-up: opt-in (`cfgCatchupOptIn`), cap 6h, scene ort/anwesend restored.
