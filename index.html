Einstellungen

Erzählerin: Offline (lokal)

Die Online-Erzählerin braucht einen kostenlosen Schlüssel. Ohne Schlüssel bleibt die Offline-Erzählerin aktiv — sie ist lokal, privat und braucht kein Netz. Schlüssel werden nur in diesem Browser gespeichert und nie hochgeladen.

Hol einen unter Google AI Studio → API-Schlüssel (ein Klick „Create API key“).
Falls du Pollinations nutzt: Key unter enter.pollinations.ai — aktiviert den gen.pollinations-Pfad. Ohne Key ist Gratis-Pollinations derzeit oft nicht erreichbar.
